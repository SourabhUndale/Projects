## App Features Requirement (Customer Side)



##### 1\. User Registration \& Login

* Mobile number + OTP based login



* Option to store user profile (Name, Flat No, Building Name, Society Name, Phone)



##### 2\. User Dashboard

* Display greeting and delivery info ("Orders placed before Friday will be delivered this weekend")



* Available stock for the week (auto-refresh every Monday)



* Browse products by category (Veggies, Fruits, Leafy Greens, etc.)



##### 3\. Product Listing Page

* Product name, image, price per kg/unit, quantity selection (+/-), available stock



* Label: “Fresh Stock Available” (only when updated Monday)



* Cart button



##### 4\. Cart \& Checkout

* Cart with list of selected items, total amount



* Delivery address (choose saved address or add new address)



* Delivery note (optional)



* Payment gateway integration (UPI, Card, Net Banking)



##### 5\. Order Confirmation

* On successful order:



* Order Summary



* Unique Order ID



* Delivery Timeline ("Delivery expected this weekend")



* SMS / WhatsApp / App Notification confirmation



##### 6\. My Orders

* Show order history



* Status (Pending, Confirmed, Delivered)



* Option to reorder



##### 7\. Profile

* View / edit address



* Change mobile number (OTP re-verification)



* Logout option





## Admin Panel (App or Web) Requirements



##### 1\. Stock Management

* Upload stock every Monday



* Upload in bulk or manually:



* Product name



* Description



* Price per kg/unit



* Stock quantity



* Image



##### 2\. User Management

* View all registered users



* Filter by society/building/flat



* Order reports by user



##### 3\. Order Management

* See weekly orders



* Filter by:



Date



Building



Flat



Delivery Status



* Export order sheet (Excel/PDF)



##### 4\. Delivery Management

* Mark orders as "Out for delivery" or "Delivered"
